# Install Hambelela Driver on Android

Use Android 8 or later with an up-to-date Chrome browser. The app uses the existing live portal in a verified full-screen Android window; Chrome supplies the web engine, but the driver launches **Hambelela Driver** from its own icon.

1. Open the provided APK download link on the driver's phone.
2. Open `Hambelela-Driver-1.0.1.apk` from Downloads and choose **Install** or **Update**. Existing 1.0.0 installations can be updated without uninstalling.
3. Android may ask you to allow installation from the browser or Files app. Allow that source only if you trust this supplied release. You can turn this allowance off after installation. Do not disable Play Protect or ignore a harmful-app warning.
4. Open **Hambelela Driver** and sign in with the driver's existing name and PIN. No new account is required. Never send the PIN in chat.
5. If another portal user is already signed in on that phone, sign out first. The app may share the portal session with Chrome.

## First phone check

Check that the dashboard opens without a browser address bar, shows the correct driver and current assignments, and that navigation and automatic updates behave normally. On the next legitimate delivery, confirm photo/signature capture, payment recording and completion. Allow camera and location only when needed for the existing functions. Confirm that calling and map directions open correctly.

Do not create false deliveries, cash receipts or financial handovers for testing.

## What stays the same

The same approved screens, server permissions, orders, errands, messages and handovers are used. Website changes continue to appear without rebuilding the APK. Native package or signing changes require installing a new APK signed with the same key; do not uninstall first when updating.

Internet is still required. This package does not add offline transaction syncing, background tracking, or push alerts while the app is closed. Those require separate implementation.

If a browser toolbar appears, update Chrome and check connectivity; domain verification must succeed. Do not disable verification. If Android refuses installation, send the exact message and phone model, not account credentials.
